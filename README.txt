CATATAN KEUANGAN — PWA

Cara memasang sebagai aplikasi di HP:
1. Unggah SEMUA file dalam folder ini ke hosting yang menyediakan HTTPS.
2. Buka alamat website tersebut dari Chrome di Android.
3. Pilih menu browser → "Tambahkan ke layar utama" / "Install app".
4. Di iPhone, buka di Safari → Bagikan → "Add to Home Screen".

Catatan:
- PWA membutuhkan HTTPS agar Service Worker dapat aktif (localhost juga aman untuk pengujian).
- Data transaksi disimpan di penyimpanan browser/perangkat. Jika data browser dihapus atau berpindah perangkat, data tidak otomatis ikut pindah.
